DCS World 日本語化ファイルアーカイブ

旧アップローダーの保存ファイルを検索・ダウンロードできます。

このアーカイブについて

本プロジェクトは、非公式の有志コミュニティによるアーカイブ活動です。DCS World の公式プロジェクトではありません。また、DCS World 日本語化ファイルアップローダーとは独立して運営しています。

保存されているファイルや翻訳内容は古くなっている可能性があります。
現在の DCS World では正常に動作しない場合があるほか、翻訳内容も現在の仕様や原文と一致しない場合があります。利用前に、各ファイルの投稿日時や対応バージョンをご確認ください。

uploader.jp の閉鎖に伴い、DCS World 日本語化ファイルアップローダー（旧アップローダー）に投稿されたすべてのファイルをバックアップし、保存するために発足したプロジェクトです。

uploader.jp の閉鎖後は、速やかに GitHub のアーカイブ機能で本リポジトリを読み取り専用にします。

本プロジェクトは、旧アップローダーの管理者から許可を得たうえで、投稿ファイルのアーカイブ化を行っています。

本プロジェクトでは、新規投稿や修正ファイルの再アップロードは受け付けません。
