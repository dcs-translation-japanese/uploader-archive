# DCS World 日本語化ファイルアーカイブ

> [!IMPORTANT]
> 本プロジェクトは、**非公式の有志コミュニティによるアーカイブ活動**です。DCS World の公式プロジェクトではありません。また、DCS World 日本語化ファイルアップローダーとは独立して運営しています。

uploader.jp の閉鎖に伴い、DCS World 日本語化ファイルアップローダー（旧アップローダー）に投稿されたファイルを保存するプロジェクトです。

uploader.jp の閉鎖後は、速やかに GitHub のアーカイブ機能で本リポジトリを読み取り専用にします。

本プロジェクトは、旧アップローダーの管理者から許可を得たうえで、投稿ファイルのアーカイブ化を行っています。

本プロジェクトでは、新規投稿や修正ファイルの再アップロードは受け付けません。

保存ファイルの閲覧・ダウンロードは、[アーカイブサイト](https://dcs-translation-japanese.github.io/uploader-archive/)から行えます。

## 問い合わせ・報告先

本プロジェクトや保存ファイルに関する問い合わせ・報告・削除要請は、本リポジトリの GitHub オーナーへご連絡ください。DCS World の開発元や旧アップローダーの管理者への問い合わせはお控えください。

`dcs.translation.japanese+uploader-archive[at]gmail.com`

送信時は `[at]` を `@` に置き換えてください。
